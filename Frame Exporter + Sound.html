Good to know

        
    
          
  1. Use Chrome or Edge on a computer for the best results. Keep this tab in front while exporting.
    2. 
          
  2. On Chrome or Edge on a computer the sound effects are built into the MP4. On iPad or iPhone, use Create sound effects and Save WAV, then combine the MP4 and WAV in an editing app. Add your voiceover there too.
    3. 
          
  3. Portrait animations export as 9:16 and landscape ones as 16:9. QHD and 4K are scaled up from the animation's own picture. Text labels are redrawn at the full size, so they stay sharp.
    4. 
          
  4. If your file has its own buttons or timeline around the picture, untick "Include text labels" so only the 3D picture is exported.
    5. 
          
  5. Heavy effects: window.renderAt(t) may be async and return a promise that finishes when the frame is fully drawn. A file may also define window.renderAudio(duration, sampleRate), which returns an AudioBuffer (built with OfflineAudioContext) of sound effects that gets added to the MP4 as an audio track. A file may also define window.prepare(progress), an async function that runs once before export, for example to pre-bake a physics or particle simulation. During export, frames are always requested in order from 0 upward.
    6. 
          
  6. The file must define window.DURATION and window.renderAt(t). A page that runs its own player loop and hides these inside a function cannot be exported until they are exposed.
    7. 
          
  7. Labels are redrawn frame by frame, so a 70 second video with labels can take several minutes. Turn labels off for a fast test.
    8. 
          
  8. If the first label method fails, the exporter switches to a simpler one by itself. It draws text, solid boxes, borders and SVG lines, but not gradients or shadows on labels.
    9. 
          
  9. Not every phone or tablet can encode 4K or 90 fps. The page tells you if yours cannot.
